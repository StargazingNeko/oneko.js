# oneko.js

A hacky script [adryd325](https://github.com/adryd325/) wrote to put a cat on their site.
I redid some of  it's logic to allow toggling between a chase and resting state, maybe some other things later such as allowing a speed override.

The default image is `oneko.gif` in the same directory as the script. This can be changed by adding `data-cat="yourimage.png"` to your `<script>` tag.

Original demo: https://adryd.com
My demo: https://xneko.moe
